# PROJET — PLATEFORME INTELLIGENTE DE CRÉATION DE SITES WEB PROFESSIONNELS

## 1. VISION DU PROJET

Créer une plateforme web moderne, premium et intuitive permettant à n'importe quel professionnel de construire gratuitement la maquette complète de son futur site internet.

La plateforme doit fonctionner comme un :

"Website Builder + configurateur visuel + générateur de prospects"

Le client doit pouvoir créer son futur site sans avoir besoin de connaître HTML, CSS, JavaScript ou autre technologie.

IMPORTANT :

Le prix NE DOIT PAS être affiché au début du parcours.

Le client doit d'abord pouvoir :

- choisir son activité ;
- choisir les fonctionnalités ;
- choisir un thème ;
- choisir ses couleurs ;
- créer ses pages ;
- ajouter ses produits/services ;
- ajouter ses images ;
- personnaliser son site ;
- voir son site en temps réel ;
- tester le site comme un véritable visiteur ;
- tester Desktop / Tablet / Mobile / TV lorsque pertinent.

Il doit pouvoir faire tout cela gratuitement.

Le prix n'est présenté qu'à la fin, lorsque le client a terminé ou suffisamment avancé son projet.

Le tunnel commercial doit être :

==================================================
2. OBJECTIF COMMERCIAL
==================================================

La plateforme ne doit pas être simplement un site présentant mes services.

Elle doit être un outil commercial permettant de transformer des visiteurs en prospects qualifiés.

L'idée est :

"Au lieu de simplement expliquer au client que je peux créer son site, je lui permets de commencer à construire lui-même son futur site."

Le client investit du temps dans son projet.

Il voit le résultat.

Il peut le tester.

Il peut se projeter.

Puis seulement à la fin :

"Votre site est prêt."

Cette approche doit augmenter la conversion.

IMPORTANT :

Ne jamais afficher le prix de réalisation au début.

Ne pas afficher :

"Site à partir de 300 €"

sur la landing page ou pendant les premières étapes.

Le prix est révélé après la création de la maquette.

31. RÈGLE DE L'ACOMPTE
==================================================

L'acompte doit être :

10 % du prix total

avec un minimum de 50 €.

Formule :

acompte = max(10 % du prix total, 50 €)

Exemples :

300 € → 50 €
400 € → 50 €
500 € → 50 €
600 € → 60 €
800 € → 80 €
1000 € → 100 €
1500 € → 150 €

IMPORTANT :

Cette règle doit être configurable depuis l'administration.

Ne pas coder directement la valeur dans le frontend.
